# xnLinkFinder VS Code Extension

Find endpoints while coding in VS Code.

## Features
- Real-time endpoint detection
- Syntax highlighting for discovered endpoints
- Quick actions to test endpoints

## Installation
1. Install from VS Code marketplace
2. Or install manually: `code --install-extension xnlinkfinder-vscode-1.0.0.vsix`

## Usage
- Press `Ctrl+Shift+P` and type "Find Endpoints with xnLinkFinder"
